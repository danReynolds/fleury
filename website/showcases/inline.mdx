## Run it in your terminal

From a Fleury checkout:

```sh
dart run packages/samples/bin/samples.dart inline
```

Use Tab to move, arrow keys to choose a template, and Enter to activate a control.
Escape returns from review or cancels setup. Try changing the terminal's width
while you review: the file list and configuration stack when space is tight.
Scroll to inspect the full preview; the action buttons stay in view.
This sample generates configuration in memory and prints a result; it writes no files.

<InlineRecording />

The recording captures the native app in a real PTY. Earlier output stays in
the main terminal buffer, the live region grows for review, and completion
clears that region before the command prints its result.

Want to mix several UI steps with ordinary CLI work? The
[Mix UI and CLI steps](/fleury/guides/terminal-modes/#mix-ui-and-cli-steps)
lets you open fresh forms with a text prompt between them, plus the native host loop
that makes it work.

## One form. A small host boundary.

The form returns an `InlineSetupResult` and announces when its page changes.
The native host owns the terminal; the browser host illustrates the same lifecycle.

<Tabs>
<TabItem label="Native terminal">

```dart
await runApp(
  FleuryApp(
    home: ScopeBuilder<TerminalSession>(builder: (_, session) => InlineSetup(
      onStepChanged: (step) => unawaited(session.resizeInline(step.rows)),
      onComplete: (value) {
        result = value;
        requestExit();
      },
    )),
  ),
  mode: const TerminalMode.inline(rows: 17, mouse: true),
  enableHotReload: false,
);
print(result?.summary ?? 'Setup cancelled.');
```

</TabItem>
<TabItem label="Browser preview">

```dart
SizedBox(
  height: step.rows,
  child: InlineSetup(
    onStepChanged: (value) => setState(() => step = value),
    onComplete: (value) => setState(() {
      result = value;
      finished = true;
    }),
  ),
)
```

The browser replaces the completed form with its result and an illustrated
prompt. It uses Fleury's browser renderer, not a native terminal session.

## Start small

`TerminalMode.inline(rows: ...)` opts into a bounded, full-width main-buffer
region on macOS/Linux. Height is explicit and clamped to the terminal; widgets
keep their normal layout and input behavior. Fleury restores the terminal when
`runApp` completes, so the command can print a useful result.
