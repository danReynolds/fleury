In Fleury, widgets own their interactions. A click goes to the control under
the pointer; keys go through focus. Start with controls that handle both,
then add gestures where your interface needs them.

Let's build the interactions for a notes workspace: edit a note, open its
preview, then add a file tile, a resizable divider, and a browsing pane.
The checklists follow your input. Each first tab shows the relevant method
from the running example; full source and tests are alongside it.

Our note starts with a title and a body. `TextInput` and `TextArea` already
own caret placement, selection, and keyboard editing. Try both fields:

## 4. Turn a file tile into a press target

Suppose the file browser uses a larger tile with its own held and cancelled
states. This is where `GestureDetector` earns its place. It supplies the
press lifecycle; the tile still opens the same preview as our button.

Press and release in the same cell to open. Moving to another cell cancels
the tap, even inside the tile. `onTapDown` starts feedback; `onTapUp` or
`onTapCancel` ends it.

<details>
<summary>What the full tile adds around the gesture</summary>

A custom target also needs keyboard focus, a visible focus cue, and semantics.
The full source wraps the gesture with `Focus`, `KeyBindings`, and `Semantics`;
Enter and Space share one binding through `aliases`. `SelectionArea.disabled`
keeps dragging the tile from selecting its label.

Use `Button` when its interaction fits. An outer `GestureDetector` cannot
observe an inner button's taps: the innermost target owns the press.

</details>

## 5. Make room for the note

Our workspace now has a file pane and a preview. Add a divider to resize them.
Unlike a tap, this interaction uses movement: the handle captures the drag
and keeps receiving it when the pointer leaves its bounds.

<InputPractice slot="demo" id="input.splitter" cols={38} rows={9} />

Apply `details.delta.col` in `onDragUpdate`. The arrow keys call the same
resize function; Tab reaches **Reset width**. Cancellation ends feedback and
keeps the width already reached.

<details>
<summary>Coordinates and capture</summary>

`localPosition` is relative to the target; `globalPosition` is relative to the
app. A captured drag can have local coordinates outside the target.
The first movement calls both `onDragStart` and `onDragUpdate` with the same
delta, so apply movement only in update. Padding inside a detector enlarges
its target. Clipping limits it and cancels a gesture if the target disappears.

</details>

## Take the workspace to a terminal

The browser examples receive pointer input automatically. A native app enables
clicks, drags, scrolling, and hover at startup:

```dart
runApp(const MyApp(), mode: const TerminalMode(mouseMotion: true));
```

Mouse reporting is currently opt-in because it takes over terminal text
selection. `mouse: true` enables clicks, drags, and scrolling without hover.
A terminal-specific modifier may bypass the app for native selection.

Continue with [key bindings](/fleury/guides/focus-and-keyboard/),
[focus](/fleury/guides/focus/), or [interactive styles](/fleury/guides/theming/).
