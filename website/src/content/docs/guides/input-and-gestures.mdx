Fleury apps can be used with a keyboard, a mouse, or both. Built-in controls
handle common interactions such as pressing a button and editing text. In this
guide, you'll open a note, resize a pane, and explore how a hover region works
around a button.

Drag distances are measured in terminal cells. The update callback adds
horizontal movement to the pane's width. Releasing or cancelling ends the drag
and leaves the width where you put it. Press **Tab** to reach **Reset width**.

Make a custom handle focusable, attach the arrow bindings, and expose its width
and resize actions to assistive tools. The full source shows how these fit
around the drag handler.

<details>
<summary>Coordinates and capture</summary>

`localPosition` is relative to the target; `globalPosition` is relative to the
app. A captured drag can have local coordinates outside the target.
The first movement reports both the start and update of a drag. Apply its delta
only in the update callback so the handle doesn't move twice. Padding inside a
detector enlarges its target. Clipping limits it and cancels a gesture if the
target disappears.

</details>

The button handles its own presses. Wrapping it in another gesture detector
won't observe those taps. Use the button's callback for actions and
`MouseRegion` for the surrounding hover feedback.

Wheel input has a different rule: a scroll view can pass it to an ancestor
at its edge. [Nested scrolling](/fleury/guides/lists-and-scrolling/#nested-wheel-input)
shows when to let it continue and when to contain it.

<details>
<summary>Give selectable text its own boundary</summary>

Ordinary app text is selectable by default. Use a `SelectionArea` when a region
needs its own selection callback or options. Keep labels and status messages
outside that boundary if they shouldn't be copied with the content. For text
that acts as a handle, use `allowSelect: false`.

</details>

## Enable pointer input in a terminal

The browser demos receive pointer input automatically. In a terminal, enable
clicks, drags, scrolling, and hover when starting the app:

```dart
runApp(const MyApp(), mode: const TerminalMode(mouseMotion: true));
```

Mouse reporting is opt-in because it takes over terminal text selection.
Use `mouse: true` when hover isn't needed. A terminal-specific modifier may
bypass the app for native selection.
