# Core performance pass — 2026-09-05

This continues the [core architecture audit](2026-09-04-core-performance.md)
in one PR: #216. Changes are measured and reviewed individually before the
next implementation begins. The final integrated validation is recorded
after the pass is complete.

## 1. Bulk background fill — reviewed

Commit `fe9d45a4`, based on main `8718fd33`. Replaces individual space writes
with a clipped bulk buffer fill, sharing one immutable cell and repairing
wide pairs only at the rectangle edges. The earlier audit records the
17–51% paint-phase reduction across five apps at 120×40.

Review: complete buffer/damage differential checks, wide-pair boundaries,
interactive style resolution, and image placement behavior. Full contributor
gate: 5,305 tests passed, one existing skip; all eight fast performance
gates and the terminal wire gate passed.

## 2. Reuse text measurements — reviewed

`RenderText` now reuses the widths it measured during layout. The common
single-line case uses its existing intrinsic width without another list;
multi-line text retains one integer per laid-out line. Paint also passes
its already-measured grapheme width through an internal buffer bridge, so
placement cannot repeat that measurement. No glyph cache or public API
knob is introduced.

This is a modest gain: roughly 1–5% in the five sample apps beyond bulk
fill. It is retained because it removes duplicate work and keeps layout
and placement on one width decision with little state. The
[receipt](evidence/2026-09-05-text.json) and
[all frame records](evidence/2026-09-05-text-frames.csv) contain the
alternating AOT comparison. Structural layout/repaint counters match.

Review completed before starting change 3:

- Checked empty text, wrapped/unwrapped transitions, same-width text edits,
  constraints, alignment, ellipsis, policy changes, and line-width lifetime.
- Differential placement checks match public grapheme writes for clipped,
  zero-width, narrow, wide, and interaction-style cases, including damage.
- A counting width resolver verifies zero line remeasurement at paint and
  one glyph measurement per glyph. Repeated mutations match fresh layout.
- Internal bridge remains excluded from stable public barrels.
- Core analysis, 600 rendering/selection/policy tests, and all eight fast
  performance gates passed. Embedded client source fingerprint refreshed.

The small sample-app gain does not establish an input-latency improvement.
The next candidate is background style composition, still prominent after
bulk fill.
