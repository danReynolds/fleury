THIRD-PARTY NOTICES — fleury_themes
===================================

This package contains colour values derived from the community colour schemes
listed below. Each remains the work of its respective authors and is included
here with attribution. The mapping of each palette onto Fleury's nine
ColorScheme roles is this package's own work.

No upstream source code is vendored — only published colour values.

Anyone redistributing this package should confirm these notices remain
accurate for the version they ship.
